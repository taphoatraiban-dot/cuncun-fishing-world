# CUNCUN FISHING WORLD 🎣

Standalone browser-based 3D fishing demo. This repository is separate from the CUNCUN receipt/lottery application.

## Try it
Open index.html via a static web server or enable GitHub Pages (Settings → Pages → Build and deployment → GitHub Actions).

## MVP features
- Three.js lake, pier, fishing rod, moving fish
- First-person and LIVE overview cameras
- Demo player list (up to 200 names), 10-minute tickets, casting, catching, points and leaderboard
- Boss fish toggle
- Browser-only localStorage state

## Not implemented yet
- Real-time shared multiplayer, server persistence, auth, 200-player concurrency testing
- TikTok integration, gifts, payments, Mac mini connection
- Photorealistic graphics or complete fishing physics

The app loads Three.js from a public CDN and requires internet access. No production security guarantees.
